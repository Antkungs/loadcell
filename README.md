# Arduino Weight Measurement with HX711 Load Cell

โปรเจกต์นี้ใช้ Arduino ร่วมกับโมดูล HX711 เพื่ออ่านค่าน้ำหนักจากโหลดเซลล์ (Load Cell)  
โดยแสดงผลน้ำหนักผ่าน Serial Monitor

---

## ส่วนประกอบหลัก

- **HX711**: โมดูล ADC สำหรับโหลดเซลล์  
- **Load Cell**: เซ็นเซอร์วัดน้ำหนัก  
- **Arduino**: บอร์ดไมโครคอนโทรลเลอร์ (เช่น Arduino Uno, Nano, ESP32 ฯลฯ)

---

## การเชื่อมต่อขา

| HX711 Pin | Arduino Pin          |
|-----------|---------------------|
| DOUT      | 2                   |
| SCK       | 3                   |
| VCC       | 5V (หรือ 3.3V ตามรุ่น) |
| GND       | GND                 |

---

## การใช้งานโค้ด

1. กำหนดค่า `CALIBRATION_FACTOR` ให้เหมาะสมกับโหลดเซลล์ของคุณ (ค่าตัวอย่างต้องทำการ Calibrate เอง)  
2. เชื่อมต่อโหลดเซลล์และ HX711 ตามตารางข้างต้น  
3. อัพโหลดโค้ดลง Arduino  
4. เปิด Serial Monitor ดูค่าน้ำหนักที่อ่านได้แบบ realtime (หน่วยขึ้นกับโหลดเซลล์และ calibration factor)

---

## คำอธิบายโค้ด

- `scale.begin()` เริ่มต้นการเชื่อมต่อกับ HX711  
- `scale.tare()` เคลียร์ค่าเซ็นเซอร์เพื่อให้เริ่มนับจากศูนย์ (น้ำหนักว่าง)  
- `scale.set_scale(CALIBRATION_FACTOR)` ตั้งค่าการคาลิเบรตโหลดเซลล์  
- `scale.get_units(20)` อ่านน้ำหนักโดยเฉลี่ยจาก 20 ตัวอย่างเพื่อลดเสียงรบกวน  
- แสดงน้ำหนักผ่าน Serial Monitor ทุก ๆ 0.5 วินาที

---

## หมายเหตุ

- ค่า `CALIBRATION_FACTOR` ต้องคาลิเบรตเองโดยใช้น้ำหนักที่รู้ค่าเทียบกับค่าที่อ่านได้  
- หากไม่คาลิเบรต ค่าที่อ่านได้จะไม่มีความแม่นยำ  
- การคาลิเบรตอาจทำได้โดยการวางน้ำหนักที่ทราบลงบนโหลดเซลล์ และปรับค่าให้ผลลัพธ์ถูกต้อง
